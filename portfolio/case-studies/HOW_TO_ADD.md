# How to Add the Next Case Study

1. Create a new file: `portfolio/case-studies/case-0X-[short-title].md`
2. Follow the Week 2 three-beat format:
   - **Problem:** What was the challenge?
   - **What I did:** What approach/decisions were made?
   - **Outcome:** What was the result/metric?
3. Follow the voice card: Confident, casual, honest, simple — like talking to a friend.
4. Add one line + link to `portfolio/README.md` (or index) for the new case.
5. Commit + push to the GitHub repo.
